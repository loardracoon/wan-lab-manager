SSH console via web gateway

This project's docker-compose already starts a webssh service on port 8888. If you see this message, the topology field sshGateway.urlTemplate is empty or the service is not running. The default template is: 

"sshGateway": {
  "urlTemplate": "http://{origin-host}:8888/?hostname={host}&username={user}&port={port}"
}

{origin-host} is replaced by the host you use to reach this page; {host}, {user} and {port} come from each firewall (sshHost, sshUser, sshPort).
